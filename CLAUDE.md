# Consignes pour les assistants IA

Les consignes complètes sont dans **`AGENTS.md`**, à la racine de ce dépôt.
Lis-le en entier avant ta première modification.

Ce fichier existe parce que chaque outil cherche un nom différent. Il ne
duplique pas les règles — deux copies finissent toujours par diverger, et une
note périmée a déjà coûté des fonctionnalités entières sur ce projet.

Les trois règles qu'on ne discute pas, reprises ici pour qu'aucun outil ne les
manque :

1. **Ne pousse jamais sur `main`.** Ni directement, ni en forçant.
2. **Ne merge jamais une pull request toi-même**, même verte, même triviale.
3. **Lance toute la vérification en local avant de pousser** — voir
   `DEMARRAGE.md`. Ne compte pas sur la CI pour découvrir que ça casse.

Rien de tout cela n'est imposé techniquement : le plan GitHub gratuit
n'autorise pas la protection de branche sur un dépôt privé. Rien ne t'arrêtera.
Ce n'est pas une permission.

Pour démarrer sur ce dépôt : `DEMARRAGE.md`.
Pour comprendre le projet : `PROJET.md`.
